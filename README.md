# 키워드 분석기 (로컬)

네이버 검색량·연관 키워드·트렌드·섹션 분석, AI 키워드 생성, 중복 검사, 대량 분석을 내 PC에서 돌리는 도구예요.

> **AI·개발자용 안내는 [AGENTS.md](AGENTS.md)** 에 있어요: GitHub 자동 백업 구조, 파일 구조, 수정 후 해야 할 일, 지켜야 할 규칙.

## 새 PC에 설치하기 (어디서든 같은 환경으로)

1. **Node.js 설치** (한 번만): https://nodejs.org 에서 LTS 설치. 또는 명령 창에서 `winget install OpenJS.NodeJS.LTS`
2. **코드 받기**: GitHub 저장소(https://github.com/hsiedev/keyword-tool, 비공개라 로그인 필요) > 초록색 [Code] > [Download ZIP] → 원하는 폴더에 압축 풀기
   (git이 있으면 `git clone https://github.com/hsiedev/keyword-tool.git`)
3. 폴더 안의 **start.bat** 더블클릭 → 브라우저에서 http://localhost:8787 이 열려요.
4. 오른쪽 위 ⚙ **설정 > API 설정**에서 키 다시 넣기 (보안 때문에 키는 GitHub에 올리지 않아요)
   - 네이버 API: 검색광고 API 키·비밀키·CUSTOMER_ID, 검색 API Client ID·Secret
   - AI 모델: Gemini API 키, 또는 로그인형 AI [설치] → [로그인]
   - GitHub 백업: 이 PC에서도 자동으로 올리려면 저장소와 토큰 입력
5. 화면·규칙 설정(data\settings.json)은 저장소에 들어 있어서 그대로 이어져요. 기존 키워드 목록·대량 분석 내역은 기본으로 올리지 않아요 (GitHub 백업 탭에서 켤 수 있어요).

## GitHub 자동 백업

- 서버가 켜져 있으면 파일이 바뀐 뒤 30초 안에 비공개 저장소에 자동으로 올라가요. 서버를 켤 때도 한 번 확인해요.
- 바뀐 내용은 저장소의 Commits에 기록되고, 기능 단위 요약은 CHANGELOG.md에 있어요.
- 올리지 않는 것: config.json(키), data\github.json(토큰), cache.json, backup\, 기존 키워드·대량 분석 내역(선택).
- 상태 확인·[지금 올리기]: 설정 > API 설정 > GitHub 백업.

# 키워드 분석기 (로컬, 네이버)

블랙키위 키워드 분석 화면을 참고해서 만든 로컬 도구예요. 외부 패키지 없이 Node.js만 있으면 돌아가요.

## 실행

1. `start.bat` 더블클릭 → 검은 창이 뜨고 브라우저에서 http://localhost:8787 이 열려요
2. 오른쪽 위 **API 설정**에서 키 입력 → 저장 → 연결 테스트
3. 키워드 입력 후 분석

키가 없는 API의 항목은 **미표시**로 나와요 (가짜 숫자를 넣지 않음). **섹션 분석은 키 없이도 실제 데이터**로 작동해요.

## 필요한 API 키 (모두 무료)

|키|발급처|쓰이는 곳|
|-|-|-|
|검색광고 API (액세스 라이선스, 비밀키, CUSTOMER\_ID)|searchad.naver.com > 도구 > API 사용 관리|월간 검색량, 연관 키워드, 클릭수·클릭률·경쟁 정도, 순위별 입찰가|
|오픈 API (Client ID, Secret)|developers.naver.com > 애플리케이션 등록 (검색 + 데이터랩(검색어트렌드) 추가)|트렌드, 이번 달 예상 검색량, 블로그·카페 발행량, 성인 키워드, 오타 교정|

키는 이 폴더의 `config.json`에만 저장돼요. 조회 결과는 `cache.json`에 12시간 캐시돼요 (섹션 분석은 1시간).

## 참고

* 검색량이 10 미만이면 네이버가 `< 10`으로만 알려줘요 (계산에는 5로 처리).
* 트렌드 환산값은 추정치예요. 검색광고 월간 검색수(최근 30일)를 데이터랩 최근 30일 지수 합계에 맞춰 비율을 곱해요.
* 섹션 분석은 로그아웃 상태의 네이버 검색 결과 기준이고, 네이버 화면 구조가 바뀌면 `sections.mjs`를 고쳐야 해요.
* 너무 빠르게 연속 조회하면 네이버가 일시적으로 막을 수 있어요.
* 포트를 바꾸려면: `set PORT=9000 \&\& node server.mjs`



## AI 키워드 생성기 (오른쪽 위 버튼)

- **필요한 키:** Gemini API 키 (aistudio.google.com/apikey, 개인 구글 계정). 기본 모델은 `gemini-3.8-flash`이고, 설정의 [모델 목록]에서 바꿀 수 있어요.
- **① 주제와 예시:** 주제와 예시 키워드를 넣고 생성해요. [이어서 더 생성]을 누르면 이미 받은 키워드를 피해서 추가로 받아요.
- **진행 표시:** 생성 중에는 버튼 아래에 진행률(작성된 키워드 수 / 요청 수), 경과 시간, 사용 중인 모델, Gemini 생각 과정 요약이 실시간으로 나와요. [중지]로 멈출 수 있어요. 생각 요약을 지원하지 않는 모델은 요약 없이 바로 생성해요.
- **② 기존 키워드:** xlsx, CSV, TXT(UTF-8/EUC-KR 모두 가능, TXT는 줄바꿈·쉼표·탭 구분)를 끌어다 놓고 시트와 열을 고르면, PC 안에서만 읽어서 중복을 검사해요. 예전 .xls 파일은 xlsx로 저장한 뒤 올려주세요.
- **중복 검사 구분**
  - 중복: 띄어쓰기, 대소문자, 기호만 다르거나 어순만 다른 경우
  - 유사: 기존 키워드를 포함하거나, 기존 키워드에 포함되거나, 1글자만 다른 경우 (숫자가 다르면 제외)
  - 의미 중복: [의미 중복 검사]를 눌렀을 때 Gemini가 검색 의도가 같다고 판단한 경우. 이때 후보마다 글자가 비슷한 기존 키워드 최대 5개만 Gemini로 보내요.
- **그 밖의 기능:** [검색량 붙이기](검색광고 API)와 [엑셀 다운로드](현재 필터 기준 xlsx)를 쓸 수 있어요. 결과와 불러온 목록은 브라우저에 저장돼서 다시 열어도 남아 있어요.
- **무료 키 주의:** 무료 등급 키는 보낸 내용이 구글 모델 개선에 쓰여요. 그래서 기존 키워드 목록은 기본적으로 보내지 않아요.

- **주제별 탭 (왼쪽 사이드바)**
  - 생성기를 열면 항상 빈 "새 탭"으로 시작해요. 주제를 입력하거나 키워드를 생성하면 그 탭이 "기록"에 저장돼요.
  - 탭마다 주제, 예시, 요청 사항, 글자 수 범위, 결과, 검증 기록이 따로 저장돼요. 기존 키워드 목록(②)은 모든 탭이 같이 써요.
  - 탭을 우클릭하면 상단 고정, 이름 변경, 삭제를 할 수 있어요.
  - 생성이나 재검증이 진행 중일 때는 탭을 바꿀 수 없어요.
- **조건 재검증**
  - [조건 재검증]을 누르면 Gemini가 탭의 주제, 예시, 요청 사항을 기준으로 각 키워드를 적합 또는 부적합으로 판정해요. 체크한 키워드가 있으면 그것만, 없으면 전체를 판정해요.
  - 누를 때마다 판정이 쌓여요. 2회 이상 모두 적합이면 "일관 적합", 모두 부적합이면 "일관 부적합", 섞이면 "판정 엇갈림"으로 표시돼요.
  - 매번 이전 판정을 알려주지 않고 새로 판단하게 해서, 판정이 일관된지 볼 수 있어요.
  - 글자 수 범위는 AI가 아니라 PC에서 정확히 계산해 "글자 수 범위 밖"으로 표시해요.
  - 엑셀로 내보내면 검증 결과, 적합 횟수, 검증 횟수, 마지막 판정 사유가 함께 들어가요.
- **검색량 자동 조회:** 검색광고 API 키가 있으면 키워드를 생성하거나 직접 추가하자마자 월간 검색량, PC, Mobile, 경쟁 정도를 자동으로 붙여요. 키가 없으면 검색량 칸에 "키 필요"가 표시돼요.
- **재검증 진행 표시:** 재검증 중에는 보라색 영역 아래에 진행률(판정한 개수 / 전체), 경과 시간, Gemini 생각 과정이 나오고 [중지]로 멈출 수 있어요. 50개씩 묶어서 판정하고, 중지하면 끝난 묶음까지만 반영돼요.
- **모델 고정:** 모델 드롭다운 옆 [모델 고정]이나 API 설정 > ③에서 켜고 꺼요.
  - **끔 (기본):** 모델이 바쁘면(503) 같은 모델로 2초, 4초 뒤 다시 시도한 다음 다른 모델로 넘어가요.
  - **켬:** 선택한 모델로만 돌려요. 바쁘면 3, 6, 12, 20, 30초 간격으로 5번(약 70초) 다시 시도하고, 그래도 안 되면 멈추고 알려줘요. 기다리는 동안 남은 초가 표시되고 [중지]로 바로 멈출 수 있어요.
  - **무료 한도 초과(429):** 구글이 알려준 대기 시간이 60초 이하면 한 번만 기다렸다 다시 시도하고, 아니면 바로 멈춰요.
- **제외 목록:** 부적합 판정을 받은 키워드를 지우면(체크 삭제, ✕, 결과 비우기, 새로 생성 모두 해당) 그 탭의 제외 목록에 사유와 함께 저장돼요. 다음 생성 때는 Gemini에 "다시 제안하지 말고 비슷한 유형도 피하라"고 알려주고, 그래도 나오면 PC에서 걸러요("이전 부적합 n개 제외"). 결과 표 아래 빨간 상자에서 목록을 보고, 하나씩 제외를 해제하거나 전체를 비울 수 있어요.
- **검색량 반영 재검증:** 재검증할 때 키워드마다 월간 검색량을 Gemini에 같이 보내 판단에 참고하게 해요. 네이버가 "<10"으로만 알려주는 값은 0으로 세요. 표에서는 PC와 모바일이 모두 10 미만이면 "<20", 한쪽만 10 미만이면 "40~49"처럼 범위로 보여줘요. 보라색 영역의 **최소 월간 검색량**(기본 50, 탭마다 저장)보다 적거나 네이버 데이터가 없는 키워드는 PC에서 정확히 계산해 부적합으로 처리하고, 사유를 "검색량 부족 (20 < 100)"처럼 표시해요. 0으로 두면 검색량 기준 없이 Gemini 판단만 써요. 검색량이 아직 없는 키워드는 판정 전에 자동으로 조회해요.
- **부적합 선택 / 삭제:** [부적합 선택]을 누르면 적합 판정을 한 번도 받지 못한 키워드만 체크되고 목록이 부적합으로 걸러져요. 판정이 엇갈린 키워드는 빠져요. 이어서 [체크한 키워드 삭제]를 누르면 확인 후 지워져요.
- **직접 제외:** 표에서 원하는 키워드를 체크하고 보라색 영역의 [체크한 키워드 제외]를 누르면 판정과 상관없이 제외 목록에 들어가고 결과에서 빠져요(사유: 직접 제외).
- **생성 시 동일 키워드 자동 제외:** 새로 받은 키워드 중 기존 키워드(②), 예시, 현재 결과, 제외 목록과 띄어쓰기·대소문자·기호만 다른 것은 결과에 넣지 않고, 몇 개를 뺐는지 메시지로 알려줘요.
- **띄어쓰기 없음:** 생성되는 키워드와 직접 추가하는 키워드는 모두 띄어쓰기 없이 붙여서 저장돼요(예: 운전자보험추천). Gemini에도 붙여 쓰라고 지시하고, 띄어 쓴 답이 와도 PC에서 붙여요. 예전에 띄어 쓴 채로 저장된 탭은 열 때 자동으로 붙이고, 붙이면서 같아진 키워드는 하나만 남겨요.
- **기존 키워드 목록 관리:** 올린 목록은 이 폴더의 data\existing-keywords.json 파일에 저장돼서 브라우저를 바꿔도 유지돼요(예전에 브라우저에 저장된 목록은 처음 열 때 자동으로 옮겨져요). ②에서 목록마다 체크로 켜고 끌 수 있고, [이 탭에서 기존 키워드로 중복 검사]를 끄면 아예 쓰지 않아요. 켜고 끈 상태는 탭마다 따로 기억하고, 새 탭은 모든 목록이 켜진 채로 시작해요. [삭제]는 파일에서 지우는 거라 모든 탭에서 사라져요.
- **기존 키워드를 Gemini에 전달 (기본 켜짐):** 생성할 때 ②에서 켜 둔 목록을 Gemini에 같이 보내서, 같은 키워드나 대소문자·어순만 다른 키워드, 뜻이 사실상 같은 키워드를 처음부터 피하게 해요. 최대 2,000개까지 보내고, 더 많으면 주제·예시와 글자가 많이 겹치는 것부터 골라 보내요. 체크를 끄면 그 선택이 기억되고, 받은 결과는 어느 쪽이든 PC에서 한 번 더 중복 검사해요.
- **요청 사항 (대화형):** 예시 키워드 칸은 키워드만 넣고, 대상·상황·제외할 것 같은 지시는 '요청 사항' 칸에 문장으로 자유롭게 써요. 문장 그대로 Gemini에 전달되고, 조건 재검증의 판정 기준으로도 쓰여요.

## 키워드 중복 검사 (오른쪽 위 버튼)

- ① 신규 키워드, ② 기존 키워드에 txt·xlsx·csv 파일을 넣거나 붙여넣고 [중복 검사]를 눌러요. 여러 파일을 한꺼번에 넣어도 되고, 엑셀은 시트와 열을 고를 수 있어요. AI 생성기 ②에 저장된 기존 키워드 목록도 체크해서 함께 비교할 수 있어요.
- 겹침 기준: 띄어쓰기·대소문자·기호만 다른 똑같은 키워드는 항상 빼요. 단어 순서만 다른 키워드(기본 켬), 비슷한 키워드(포함·1글자 차이, 기본 끔, 끄면 '확인 필요'로만 표시), 신규 목록 안의 중복(기본 켬)은 옵션이에요.
- 결과는 남김·제외·확인 필요로 나눠 보여주고, 남은 키워드만 엑셀·TXT·CSV로 내려받거나 복사할 수 있어요. 엑셀에는 '제외된 키워드'와 '확인 필요' 시트(사유, 겹친 기존 키워드)도 들어가요. 기본으로 띄어쓰기를 없애고 저장해요(옵션).
- 파일은 이 PC 브라우저 안에서만 처리하고, AI나 외부로 보내지 않아요.

## 대량 키워드 분석 (오른쪽 위 [대량 분석])

- txt·xlsx·csv 파일이나 붙여넣기로 키워드를 넣으면(최대 1,000개, 띄어쓰기는 붙여서 조회, 중복은 하나만) 키워드마다 월간 검색량(PC·모바일), 월평균 클릭수·클릭률, 경쟁 정도, 노출 광고수를 조회해요.
- 옵션: 순위별 평균 입찰가(PC·모바일 1~5위, 기본 켬), 블로그 누적 발행량·포화 지수(검색 API 키가 있을 때, 기본 켬).
- 진행률이 단계별로 표시되고, 받은 결과부터 표가 바로 채워져요. [중지]하면 받은 데까지 남아요.
- 표는 정렬, 키워드 검색, 최소·최대 검색량, 경쟁 정도 필터를 지원하고, 필터한 그대로 엑셀·CSV로 받을 수 있어요(입찰가는 1~5위 전부 포함). 키워드를 누르면 상세 분석으로 넘어가요.
- 결과는 12시간 캐시를 써서 같은 키워드를 다시 조회하면 빨라요. 마지막 결과는 브라우저에 남아 다시 열어도 보여요.

## 설정 (오른쪽 위 [설정])

- **API 설정**: 네이버 API / AI 모델 키 입력 (예전 API 설정 창).
- **화면 · 커스텀**: 사이트 이름, 강조 색, 화면 배율, 표 간격, 숫자 표기, 시작 화면, 숨길 상단 버튼, 표 한 페이지 행 수, 설정 내보내기·불러오기(JSON).
- **규칙 · 알고리즘**: 각 기능의 계산 원리 설명과 바꿀 수 있는 기준.
  - 키워드 분석: 포화 지수 구간, 키워드 등급 기준, 이슈성 구간, 정보성/상업성 단어·가점·구간
  - AI 생성: AI 역할 문장, 생성 규칙, 띄어쓰기 없애기, 창의성(Gemini)
  - 조건 재검증: 판정 기준, 검색량 참고 여부, '일관' 횟수, '<10' 계산값, 새 탭 최소 검색량, 창의성(Gemini)
  - 중복 검사(AI 생성기·중복 검사 탭 공통): 무시할 기호, 대소문자, 어순, 1글자 차이·포함 최소 길이, 숫자 규칙, 의미 중복 후보 기준, 같은 말 사전
- 화면·규칙 설정은 data\settings.json에 저장돼요. 섹션마다 [기본값으로], 전체 초기화도 있어요.

## 대량 분석 > AI 조건 재검증

- 분석 결과가 있으면 결과 위에 'AI 조건 재검증' 칸이 생겨요. 주제·예시·요청 사항·최소 월간 검색량을 넣거나, [조건 가져오기]로 AI 키워드 생성기 탭의 조건을 그대로 가져올 수 있어요.
- 대상: 전체 / 지금 표에 보이는 키워드(필터 적용) / 체크한 키워드. 50개씩 묶어서 AI에 보내요.
- 판정 방식은 AI 생성기 재검증과 같아요(설정 > 규칙·알고리즘 > 조건 재검증). 최소 검색량 미만은 PC가 부적합 처리.
- 표에 'AI 판정' 열(일관 적합/엇갈림/부적합 + 판정 기록 점), 판정 필터, 체크박스, [부적합만 체크] → [체크한 키워드 삭제].
- 엑셀/CSV에 AI 판정, 적합/판정 횟수, 최근 판정 근거 열이 추가돼요.

## 대량 분석 > 내역 탭 · 재검증 AI 선택

- 왼쪽 사이드바에 분석 내역이 쌓여요. [분석 시작]을 누를 때마다 새 탭이 만들어지고, 결과가 있는 탭에서 다시 분석해도 이전 결과는 내역에 남아요 (재검증 조건은 이어받음).
- 탭 우클릭: 상단에 고정 / 이름 변경 / 삭제. 이름은 파일명이나 '첫 키워드 외 N개'로 자동으로 붙어요.
- 결과·판정 기록·재검증 조건은 data\bulk-history\ 폴더에 탭마다 파일로 저장돼요 (index.json = 목록). 예전 버전의 마지막 결과는 처음 열 때 내역으로 옮겨져요.
- AI 조건 재검증 칸에서 AI(Gemini/Claude/GPT)와 모델을 따로 고를 수 있어요. AI 키워드 생성기의 선택과는 별개로 기억하고, 전체 설정은 바꾸지 않아요. 키가 없는 AI는 '(키 없음)'으로 표시돼요. '모델 고정' 설정은 공통이에요.

## 결과 필터 (대량 분석 · 키워드 중복 검사 · AI 생성기 공통)

- 키워드 검색(여러 단어는 띄어쓰기, 모두 포함), 제외 단어, 숫자 범위(최소~최대, 그 값 포함). 쉼표(1,000)도 돼요.
- 대량 분석: 월간 검색량 + [상세 필터]에 PC·모바일 검색량, 월 클릭, 클릭률, 광고수, PC/MO 1·3위 입찰가, 블로그 누적, 포화 지수, 글자 수.
- 중복 검사: 글자 수 범위. 필터가 켜져 있으면 다운로드·복사도 필터에 맞는 키워드만. [남은 키워드 대량 분석 →]으로 검색량 조회까지 이어서.
- AI 생성기: 월간 검색량, PC, 모바일, 글자 수.
- 최소가 최대보다 크거나 숫자가 아니면 빨갛게 표시돼요. 값이 없는 키워드는 범위를 지정하면 빠져요.

## AI 생성기 자동 저장

- 적는 즉시(입력을 멈추고 0.5초 뒤), 칸을 벗어날 때, 창을 닫거나 새로고침할 때 저장돼요.
- 새 탭은 주제가 없어도 예시·요청 사항 중 하나라도 적으면 기록에 올라가요.

## 판정 엇갈림 정리 (AI 생성기 · 대량 분석)

- 재검증이 끝났을 때 판정이 엇갈린 키워드가 있으면 창이 떠서 적합 / 부적합 / 보류를 물어봐요. [엇갈림 정리] 버튼이나 표의 '어느 쪽으로 할지 정하기'로도 열 수 있어요.
- AI가 댄 부적합 사유별로 묶어서 보여주고, 묶음 단위·전체 단위로 한 번에 고를 수 있어요.
- 고른 결과는 '적합 (직접)' / '부적합 (직접)'으로 확정되고 다음 재검증에서 빠져요 (체크한 키워드 대상이면 포함). 보류는 엇갈림 그대로.
- '내 결정을 AI에게 예시로 알려주기'(기본 켜짐): 다음 재검증 때 최근 결정 60개를 판정 기준 아래에 예시로 붙여 비슷한 키워드를 같은 기준으로 판정하게 해요.
- 표의 [직접 판정 취소]로 되돌릴 수 있고, [판정 기록 지우기]는 직접 판정도 함께 지워요.

## 화면 디자인 (shadcn 대시보드 스타일 · 라이트/다크)

- 스타일: public\app.css (색은 모두 변수), 틀: public\layout.js. 예전 화면 파일은 backup\public_before_ui_* 폴더에 있어요 (그 폴더 내용을 public에 덮어쓰면 원래대로).
- 글꼴은 Pretendard(인터넷 연결 시), 없으면 맑은 고딕.

## 자동완성 · 관련 검색어 (키 없이)

- 키워드 분석 화면의 '자동완성·관련 검색어' 탭: 네이버 통합검색 하단 관련 검색어, 네이버 자동완성, 구글 자동완성을 한 번에 모아요.
- [넓게 수집 (ㄱ~ㅎ)]: 키워드 뒤에 자음을 붙여 자동완성을 한 번 더 모아요 (10초쯤).
- 초록 점은 연관 키워드 표(검색량 있음)에도 있는 키워드예요. [대량 분석으로 보내기]로 나머지의 검색량·입찰가를 바로 조회할 수 있어요. AI 생성기 예시로 보내기, TXT, 복사도 돼요.
- 공개 검색창에서 가져오는 방식이라 네이버·구글이 구조를 바꾸면 안 될 수 있어요. 결과는 6시간 저장해 두고 다시 써요.

## AI 카피 생성기

1. 왼쪽 메뉴 **AI 카피 생성기** (또는 분석 화면의 [카피 만들기])
2. **광고 형식**: 파워링크 / 브랜드검색 → 형식 고르기. 글자 수 규격이 바로 아래 보여요 (띄어쓰기 포함으로 셈)
3. **브랜드 정보**: 업체 이름 · 사이트 이름 · 강점 · **혜택·근거**. 카피에 들어가는 숫자·혜택은 혜택·근거 칸에 있는 것만 쓰고, 없는 숫자는 노란색으로 알려줘요. [저장]하면 다른 탭에서 불러올 수 있어요
4. **대상 키워드** → [경쟁 광고 보기]: 지금 네이버(PC)에 노출 중인 파워링크 문구를 읽어서 AI에 같이 보내요 (겹치지 않게)
5. **소구 각도**를 고르고 [카피 생성]. 카드마다 글자 수와 검사 결과가 붙어요 (빨강 = 규격 오류, 노랑 = 확인 필요)
6. 카드에서 바로 고치거나 [다시 쓰기 ▾ → 검사 문제 고치기], 마음에 들면 [확정], 빼고 싶으면 [제외] (AI가 비슷하게 안 써요)
7. [AI 재검증]: 근거 없는 주장·최상급·경쟁사 언급을 AI가 한 번 더 봐요. 여러 번 돌려서 계속 적합이면 믿을 만해요
8. [네이버 모양으로 보기], [목업] (광고 목업에 넣기), TXT · CSV · 엑셀

- **검사 규칙** 버튼: 사용자 주의어(처음엔 비어 있음), 최상급 검사 켜기/끄기와 단어 목록
- 탭 내역은 `data\copy-projects\`에 저장돼요 (GitHub 백업에는 안 올라가요)

## 광고 목업

광고주센터처럼 **캠페인 › 광고그룹 › 소재 · 확장 소재**를 만들고 네이버 검색 결과 모양으로 미리 봐요.

- **파워링크**: 단일형/반응형 소재, 확장 소재(추가제목 · 추가설명 · 홍보문구 · 서브링크 · 이미지형 서브링크 · 파워링크 이미지). [미리보기]에서 미리보기 키워드를 넣으면 지금 노출 중인 경쟁 광고 사이에 내 광고를 원하는 순위로 넣어 볼 수 있어요 (PC/모바일, 반응형은 [다른 조합])
- **브랜드검색**: PC 라이트형 · PC 프리미엄형(이미지) · 모바일 라이트형(베이직/리스팅) · 모바일 프리미엄형(스토리). 이미지를 넣으면 크기 규격도 검사해요
- 표마다 **검수 예상**(통과 예상 · 확인 필요 · 보류 예상)을 보여줘요. 실제 심사 결과와 다를 수 있어요
- [PNG 저장](2배 해상도) · [HTML 저장]. 경쟁 광고의 이미지는 빼고 보여줘요
- 모양은 실제 네이버 화면을 재서 맞춘 근사치예요. 캠페인은 `data\ad-mock\`에 저장돼요 (GitHub 백업 제외)

## 구글 모드 (무료)

사이드바 맨 위의 **NAVER / Google** 토글로 바꿔요 (사이드바를 접었을 때는 N/G 버튼). 구글 모드는 지금 **키워드 분석**만 있어요.

| 칸 | 데이터 | 준비 |
|-|-|-|
| 구글 검색량 · 입찰가 · 경쟁 | 키워드 플래너 CSV | 구글 광고 › 도구 › 키워드 플래너에서 결과를 ⤓ 다운로드 → 화면에 끌어다 놓기. 광고비를 쓰지 않는 계정은 '1천~1만'처럼 범위로 나와요 |
| 네이버 검색량 (비교) | 네이버 검색광고 API | 지금 쓰는 키 그대로 |
| 자동완성 | 구글 · 유튜브 | 없음 |
| 구글 트렌드 | 웹사이트가 쓰는 비공식 주소 | 없음. 구글이 잠시 막으면(429) 트렌드 사이트에서 ⤓ 내보내기로 받은 CSV를 넣으면 돼요 |
| 유튜브 | YouTube Data API | Google Cloud에서 API 키 발급 (무료, 검색 하루 100회) → 유튜브 칸에 붙여넣기 |

- 가져온 플래너 CSV는 `data\google\planner.json`에 모아 둬요 (GitHub 백업 제외). 같은 키워드는 새 파일 값으로 바뀌어요.
- 구글 검색 결과 배치 · 경쟁 구글 광고는 무료로 가져올 방법이 없어서 [구글에서 검색], [광고 투명성 센터] 바로 가기만 있어요.
