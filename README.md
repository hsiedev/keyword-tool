# 키워드 분석기 (로컬)

네이버 검색량·연관 키워드·트렌드·섹션 분석, AI 키워드 생성, 중복 검사, 대량 분석을 내 PC에서 돌리는 도구예요.

> **AI·개발자용 안내는 [AGENTS.md](AGENTS.md)** 에 있어요: GitHub 자동 백업 구조, 파일 구조, 수정 후 해야 할 일, 지켜야 할 규칙.

> 목적, 구성도, 기능별 구현 및 저장 구조: [ARCHITECTURE.md](ARCHITECTURE.md)

## 새 PC에 설치하기 (어디서든 같은 환경으로)

1. **Node.js 설치** (한 번만): https://nodejs.org 에서 LTS 설치. 또는 명령 창에서 `winget install OpenJS.NodeJS.LTS`
2. **코드 받기**: GitHub 저장소(https://github.com/hsiedev/keyword-tool, 비공개라 로그인 필요) > 초록색 [Code] > [Download ZIP] → 원하는 폴더에 압축 풀기
   (git이 있으면 `git clone https://github.com/hsiedev/keyword-tool.git`)
3. 폴더 안의 **start.bat** 더블클릭 → 브라우저에서 http://localhost:8787 이 열려요.
4. 오른쪽 위 ⚙ **설정 > API 설정**에서 키 다시 넣기 (보안 때문에 키는 GitHub에 올리지 않아요)
   - 네이버 API: 검색광고 API 키·비밀키·CUSTOMER_ID, 검색 API Client ID·Secret
   - AI 모델: Gemini API 키, 또는 로그인형 AI [설치] → [로그인]
   - GitHub 백업: 이 PC에서도 자동으로 올리려면 저장소와 토큰 입력
5. 화면·규칙 설정(data\settings.json)은 저장소에 들어 있어서 그대로 이어져요. 기존 키워드 목록·대량 분석 내역은 기본으로 올리지 않아요 (GitHub 백업 탭에서 켤 수 있어요).

## GitHub 자동 백업

- 서버가 켜져 있으면 파일이 바뀐 뒤 30초 안에 비공개 저장소에 자동으로 올라가요. 서버를 켤 때도 한 번 확인해요.
- 바뀐 내용은 저장소의 Commits에 기록되고, 기능 단위 요약은 CHANGELOG.md에 있어요.
- 올리지 않는 것: config.json(키), data\github.json(토큰), cache.json, backup\, 기존 키워드·대량 분석 내역(선택).
- 상태 확인·[지금 올리기]: 설정 > API 설정 > GitHub 백업.

# 키워드 분석기 (로컬, 네이버)

블랙키위 키워드 분석 화면을 참고해서 만든 로컬 도구예요. 외부 패키지 없이 Node.js만 있으면 돌아가요.

## 실행

1. `start.bat` 더블클릭 → 검은 창이 뜨고 브라우저에서 http://localhost:8787 이 열려요
2. 오른쪽 위 **API 설정**에서 키 입력 → 저장 → 연결 테스트
3. 키워드 입력 후 분석

키가 없는 API의 항목은 **미표시**로 나와요 (가짜 숫자를 넣지 않음). **섹션 분석은 키 없이도 실제 데이터**로 작동해요.

## 필요한 API 키 (모두 무료)

|키|발급처|쓰이는 곳|
|-|-|-|
|검색광고 API (액세스 라이선스, 비밀키, CUSTOMER\_ID)|searchad.naver.com > 도구 > API 사용 관리|월간 검색량, 연관 키워드, 클릭수·클릭률·경쟁 정도, 순위별 입찰가|
|오픈 API (Client ID, Secret)|developers.naver.com > 애플리케이션 등록 (검색 + 데이터랩(검색어트렌드) 추가)|트렌드, 이번 달 예상 검색량, 블로그·카페 발행량, 성인 키워드, 오타 교정|

키는 이 폴더의 `config.json`에만 저장돼요. 조회 결과는 `cache.json`에 12시간 캐시돼요 (섹션 분석은 1시간).

## 참고

* 검색량이 10 미만이면 네이버가 `< 10`으로만 알려줘요 (계산에는 5로 처리).
* 트렌드 환산값은 추정치예요. 검색광고 월간 검색수(최근 30일)를 데이터랩 최근 30일 지수 합계에 맞춰 비율을 곱해요.
* 섹션 분석은 로그아웃 상태의 네이버 검색 결과 기준이고, 네이버 화면 구조가 바뀌면 `sections.mjs`를 고쳐야 해요.
* 너무 빠르게 연속 조회하면 네이버가 일시적으로 막을 수 있어요.
* 포트를 바꾸려면: `set PORT=9000 \&\& node server.mjs`



## AI 키워드 생성기 (오른쪽 위 버튼)

- **필요한 키:** Gemini API 키 (aistudio.google.com/apikey, 개인 구글 계정). 기본 모델은 `gemini-3.8-flash`이고, 설정의 [모델 목록]에서 바꿀 수 있어요.
- **대화형 브리프 (새 탭 기본):** 주제를 적으면 카드·보험·의료·B2B·쇼핑·지역 서비스에 맞는 목표와 검색 상황이 나와요. 앞에서 고른 목표나 상황에 따라 후속 질문도 달라져요. 어떤 분야인지 애매하면 직접 고르고, 모르는 조건은 `미정`으로 두세요. 다른 주제로 바꿔도 진행 중인 답변은 따로 보관되며 현재 요청에 섞이지 않아요. 검토에서 요청문을 확인한 뒤 **키워드 생성**을 누르세요.
- **일반 주제에서 질문 추가:** 직접 질문을 적거나 **AI 질문 초안 받기**를 눌러 최대 3개를 제안받아요. 버튼을 눌렀을 때만 주제 한 줄이 선택한 Gemini 모델로 전송되며, 기존 키워드·답변은 보내지 않아요. 제안은 수정·삭제할 수 있고, Gemini가 없어도 작성과 생성은 계속할 수 있어요. 기존 대화형·직접 입력 작업은 종전 방식으로 열려요.
- **의견 반영 진행:** 의견 카드에서 현재 단계, 받은 후보 수, 경과 시간과 모델을 확인하고 중지할 수 있어요.
- **생성 중 자동 재검증:** 새 탭에서는 기본으로 꺼져 있고, 켜면 해당 탭에 기억해요. 최소 월간 검색량은 새 탭 기본 30이며 기존 탭의 값은 유지돼요.
- **생성 개수:** [키워드 생성] 버튼 왼쪽에서 30·50·80·100·150개 중 선택해요(새 작업 기본 50개). [이어서 더 생성]에도 같은 값이 적용되며, 중복·제외 조건에 따라 실제 후보 수는 더 적을 수 있어요.
- **직접 입력:** 기존 브리프·참고 키워드와 결과는 그대로 열려요. 두 입력 방식을 오가도 각각 작성한 내용은 남아요. [이어서 더 생성]은 현재 결과를 보존하고, 같은 브리프일 때만 탐색 계획을 재사용해요.
- **페르소나별 결과:** 대표 시드와 구체 의도를 숏테일·롱테일로 나누고, 결과에 타깃·부모 시드·출처를 표시해요. PC·모바일 검색량은 실제 조회값만 표기하며 미조회·데이터 없음·소량·실제 0을 구분해요. 검색량이 작거나 미확인인 후보와 보류·제외 후보는 필터로 따로 볼 수 있어요. 검색량과 조건 판정은 별개이며, 직접 검색과 랜딩 확인 전에는 집행 추천이 아니에요. 엑셀과 TXT는 현재 필터 범위를 사용해요.
- **진행 표시:** 생성 중에는 버튼 아래에 진행률(작성된 키워드 수 / 요청 수), 경과 시간, 사용 중인 모델, Gemini 생각 과정 요약이 실시간으로 나와요. [중지]로 멈출 수 있어요. 생각 요약을 지원하지 않는 모델은 요약 없이 바로 생성해요.
- **② 기존 키워드:** xlsx, CSV, TXT(UTF-8/EUC-KR 모두 가능, TXT는 줄바꿈·쉼표·탭 구분)를 끌어다 놓고 시트와 열을 고르면, PC 안에서만 읽어서 중복을 검사해요. 예전 .xls 파일은 xlsx로 저장한 뒤 올려주세요.
- **중복 검사 구분**
  - 중복: 띄어쓰기, 대소문자, 기호만 다르거나 어순만 다른 경우
  - 유사: 기존 키워드를 포함하거나, 기존 키워드에 포함되거나, 1글자만 다른 경우 (숫자가 다르면 제외)
  - 의미 중복: [의미 중복 검사]를 눌렀을 때 Gemini가 검색 의도가 같다고 판단한 경우. 이때 후보마다 글자가 비슷한 기존 키워드 최대 5개만 Gemini로 보내요.
- **그 밖의 기능:** [검색량 붙이기](검색광고 API)와 [엑셀 다운로드](현재 필터 기준 xlsx)를 쓸 수 있어요. 결과와 불러온 목록은 브라우저에 저장돼서 다시 열어도 남아 있어요.
- **무료 키 주의:** 무료 등급 키는 보낸 내용이 구글 모델 개선에 쓰여요. 그래서 기존 키워드 목록은 기본적으로 보내지 않아요.

- **주제별 탭 (왼쪽 사이드바)**
  - 생성기를 열면 항상 빈 "새 탭"으로 시작해요. 주제를 입력하거나 키워드를 생성하면 그 탭이 "기록"에 저장돼요.
  - 탭마다 주제, 예시, 요청 사항, 글자 수 범위, 결과, 검증 기록이 따로 저장돼요. 기존 키워드 목록(②)은 모든 탭이 같이 써요.
  - 탭을 우클릭하면 상단 고정, 이름 변경, 삭제를 할 수 있어요.
  - 생성이나 재검증이 진행 중일 때는 탭을 바꿀 수 없어요.
- **조건 재검증**
  - [조건 재검증]을 누르면 Gemini가 탭의 주제, 예시, 요청 사항을 기준으로 각 키워드를 적합 또는 부적합으로 판정해요. 체크한 키워드가 있으면 그것만, 없으면 전체를 판정해요.
  - 누를 때마다 판정이 쌓여요. 2회 이상 모두 적합이면 "일관 적합", 모두 부적합이면 "일관 부적합", 섞이면 "판정 엇갈림"으로 표시돼요.
  - 매번 이전 판정을 알려주지 않고 새로 판단하게 해서, 판정이 일관된지 볼 수 있어요.
  - 글자 수 범위는 AI가 아니라 PC에서 정확히 계산해 "글자 수 범위 밖"으로 표시해요.
  - 엑셀로 내보내면 검증 결과, 적합 횟수, 검증 횟수, 마지막 판정 사유가 함께 들어가요.
- **검색량 자동 조회:** 검색광고 API 키가 있으면 키워드를 생성하거나 직접 추가하자마자 월간 검색량, PC, Mobile, 경쟁 정도를 자동으로 붙여요. 키가 없으면 검색량 칸에 "키 필요"가 표시돼요.
- **재검증 진행 표시:** 재검증 중에는 보라색 영역 아래에 진행률(판정한 개수 / 전체), 경과 시간, Gemini 생각 과정이 나오고 [중지]로 멈출 수 있어요. 50개씩 묶어서 판정하고, 중지하면 끝난 묶음까지만 반영돼요.
- **모델 고정:** 모델 드롭다운 옆 [모델 고정]이나 API 설정 > ③에서 켜고 꺼요.
  - **끔 (기본):** 모델이 바쁘면(503) 같은 모델로 2초, 4초 뒤 다시 시도한 다음 다른 모델로 넘어가요.
  - **켬:** 선택한 모델로만 돌려요. 바쁘면 3, 6, 12, 20, 30초 간격으로 5번(약 70초) 다시 시도하고, 그래도 안 되면 멈추고 알려줘요. 기다리는 동안 남은 초가 표시되고 [중지]로 바로 멈출 수 있어요.
  - **무료 한도 초과(429):** 구글이 알려준 대기 시간이 60초 이하면 한 번만 기다렸다 다시 시도하고, 아니면 바로 멈춰요.
- **제외 목록:** 부적합 판정을 받은 키워드를 지우면(체크 삭제, ✕, 결과 비우기, 새로 생성 모두 해당) 그 탭의 제외 목록에 사유와 함께 저장돼요. 다음 생성 때는 Gemini에 "다시 제안하지 말고 비슷한 유형도 피하라"고 알려주고, 그래도 나오면 PC에서 걸러요("이전 부적합 n개 제외"). 결과 표 아래 빨간 상자에서 목록을 보고, 하나씩 제외를 해제하거나 전체를 비울 수 있어요.
- **검색량 반영 재검증(기존 직접 입력 결과):** 재검증할 때 키워드마다 월간 검색량을 Gemini에 같이 보내 판단에 참고하게 해요. 네이버가 "<10"으로만 알려주는 값은 0으로 세요. 표에서는 PC와 모바일이 모두 10 미만이면 "<20", 한쪽만 10 미만이면 "40~49"처럼 범위로 보여줘요. 보라색 영역의 **최소 월간 검색량**(새 탭 기본 30, 탭마다 저장)보다 적거나 네이버 데이터가 없는 키워드는 PC에서 정확히 계산해 부적합으로 처리하고, 사유를 "검색량 부족 (20 < 100)"처럼 표시해요. 0으로 두면 검색량 기준 없이 Gemini 판단만 써요. 검색량이 아직 없는 키워드는 판정 전에 자동으로 조회해요.
- **부적합 선택 / 삭제:** [부적합 선택]을 누르면 적합 판정을 한 번도 받지 못한 키워드만 체크되고 목록이 부적합으로 걸러져요. 판정이 엇갈린 키워드는 빠져요. 이어서 [체크한 키워드 삭제]를 누르면 확인 후 지워져요.
- **직접 제외:** 표에서 원하는 키워드를 체크하고 보라색 영역의 [체크한 키워드 제외]를 누르면 판정과 상관없이 제외 목록에 들어가고 결과에서 빠져요(사유: 직접 제외).
- **생성 시 동일 키워드 자동 제외:** 새로 받은 키워드 중 기존 키워드(②), 예시, 현재 결과, 제외 목록과 띄어쓰기·대소문자·기호만 다른 것은 결과에 넣지 않고, 몇 개를 뺐는지 메시지로 알려줘요.
- **띄어쓰기 없음:** 생성되는 키워드와 직접 추가하는 키워드는 모두 띄어쓰기 없이 붙여서 저장돼요(예: 운전자보험추천). Gemini에도 붙여 쓰라고 지시하고, 띄어 쓴 답이 와도 PC에서 붙여요. 예전에 띄어 쓴 채로 저장된 탭은 열 때 자동으로 붙이고, 붙이면서 같아진 키워드는 하나만 남겨요.
- **기존 키워드 목록 관리:** 올린 목록은 이 폴더의 data\existing-keywords.json 파일에 저장돼서 브라우저를 바꿔도 유지돼요(예전에 브라우저에 저장된 목록은 처음 열 때 자동으로 옮겨져요). ②에서 목록마다 체크로 켜고 끌 수 있고, [이 탭에서 기존 키워드로 중복 검사]를 끄면 아예 쓰지 않아요. 켜고 끈 상태는 탭마다 따로 기억하고, 새 탭은 모든 목록이 켜진 채로 시작해요. [삭제]는 파일에서 지우는 거라 모든 탭에서 사라져요.
- **기존 키워드를 선택한 AI에 전달:** 대화형은 기본 꺼짐이며 개별 동의 후 사용해요. 직접 입력의 마지막 설정은 유지해요. 생성할 때 ②에서 켜 둔 목록을 Gemini에 같이 보내서, 같은 키워드나 대소문자·어순만 다른 키워드, 뜻이 사실상 같은 키워드를 처음부터 피하게 해요. 최대 2,000개까지 보내고, 더 많으면 주제·예시와 글자가 많이 겹치는 것부터 골라 보내요. 체크를 끄면 그 선택이 기억되고, 받은 결과는 어느 쪽이든 PC에서 한 번 더 중복 검사해요.
- **선택 조사:** 네이버 자동완성·관련검색과 검색광고 키워드 도구를 이용할 수 있어요. 외부 AI 웹 조사는 대화형에서 기본 꺼짐이에요. 공식 상품과 광고 랜딩 주소를 입력했다고 검증 완료로 표시하지 않아요.

## 빠른 이동
- **Ctrl+K** (또는 상단 검색 버튼): 키워드를 치고 Enter면 키워드 분석, Ctrl+Enter면 키워드 도구. 메뉴 이름, 관심 키워드, 최근 분석, AI 탭, 대량 분석·파워링크 내역도 같이 찾아요. ↑↓로 고르고 Esc로 닫아요.
- 표의 키워드 줄에 마우스를 올리면 작은 버튼이 나와요: ★ 관심 키워드 · ↗ 분석 · 🔍 키워드 도구 · 복사.
- 관심 키워드(★)는 이 브라우저에 저장돼요. 첫 화면과 Ctrl+K에 모여요.
- 첫 화면(키워드 분석)에는 관심 키워드 · 최근 분석 · 이어서 하기(최근 AI 탭 · 파워링크 · 대량 분석 · 키워드 도구) 카드가 나와요.

## 키워드 도구 (왼쪽 메뉴)
- 네이버 검색광고 키워드 도구와 같은 데이터(최근 30일 검색량 · 월평균 클릭수 · 클릭률 · 경쟁 · 노출 광고 수)를 분석기 안에서 봐요. 검색광고 API 키가 필요해요.
- 키워드는 최대 5개. '키워드마다 따로도 조회'를 켜 두면 결과가 더 많아지고, 연관 키워드마다 어떤 입력 키워드에서 나왔는지(찾은 기준) 보여줘요.
- 시즌 월 · 시즌 테마(설, 크리스마스, 장마 등 네이버 공식 분류)로도 찾을 수 있어요. 테마만 골라도 조회돼요.
- 내 사이트 기준: 광고 계정에 등록된 웹사이트(비즈채널) 중에서 골라요. 아무 주소나 넣는 방식은 네이버 API가 지원하지 않아요.
- 결과: 포함 · 제외 단어, 검색량 범위, 경쟁 정도, 찾은 기준으로 거르고 머리글을 눌러 정렬. 체크한 키워드(없으면 필터 결과 전체)를 대량 분석 · AI 생성기 참고 키워드로 보내거나 복사 · TXT · 엑셀로 받아요.
- 키워드 분석 화면의 [키워드 도구로] 버튼으로 지금 키워드를 바로 넣을 수 있어요. 최근 조회는 왼쪽에 쌓이고, 12시간 안에 같은 조회는 바로 나와요.

## AI 키워드 생성기 > AI에게 의견 주기
- 결과가 나오면 결과 위에 의견 칸이 생겨요. "혜택 얘기는 충분하니 발급 절차 쪽을 더", "추천이 들어간 건 그만"처럼 쓰면 돼요. 자주 쓰는 의견은 버튼으로 넣을 수 있어요.
- 좋은 키워드를 체크해 두면 '이런 결로 더' 예시로 같이 보내요.
- [의견 반영해서 더 찾기]: 지금 결과는 두고 더 찾아요 (Ctrl+Enter). [의견 반영해서 다시 만들기]: 체크한 키워드와 '적합(직접)'만 남기고 새로 만들어요.
- 의견은 탭에 대화처럼 쌓이고, 다음 생성 · 조건 재검증에도 계속 반영돼요. 필요 없는 의견은 ×로 지워요.

## 키워드 중복 검사 (오른쪽 위 버튼)

- ① 신규 키워드, ② 기존 키워드에 txt·xlsx·csv 파일을 넣거나 붙여넣고 [중복 검사]를 눌러요. 여러 파일을 한꺼번에 넣어도 되고, 엑셀은 시트와 열을 고를 수 있어요. AI 생성기 ②에 저장된 기존 키워드 목록도 체크해서 함께 비교할 수 있어요.
- ②에 텍스트를 붙여넣고 [붙여넣은 키워드 저장]을 누르면 이름을 붙여 별도 목록으로 저장해요. 띄어쓰기는 기본으로 없애고, 옵션을 끄면 유지해요. 다음에 중복 검사 또는 AI 생성기 ②에서 다시 사용할 수 있어요.
- 겹침 기준: 띄어쓰기·대소문자·기호만 다른 똑같은 키워드는 항상 빼요. 단어 순서만 다른 키워드와 비슷한 키워드(포함·1글자 차이)는 기본으로 남기고 '확인 필요'로 표시해요. 신규 목록 안의 중복 제외는 기본으로 켜져 있어요.
- 결과는 남김·제외·확인 필요로 나눠 보여주고, 남은 키워드만 엑셀·TXT·CSV로 내려받거나 복사할 수 있어요. 엑셀에는 '제외된 키워드'와 '확인 필요' 시트(사유, 겹친 기존 키워드)도 들어가요. 기본으로 띄어쓰기를 없애고 저장해요(옵션).
- 파일은 이 PC 브라우저 안에서만 처리하고, AI나 외부로 보내지 않아요.

## 대량 키워드 분석 (오른쪽 위 [대량 분석])

- txt·xlsx·csv 파일이나 붙여넣기로 키워드를 넣으면(띄어쓰기는 붙여서 조회, 중복은 하나만) 키워드마다 월간 검색량(PC·모바일), 월평균 클릭수·클릭률, 경쟁 정도, 노출 광고수를 조회해요.
- 1,000개가 넘어도 한 번에 넣으세요. 최대 1,000개씩 자동으로 조회하고 같은 내역 탭에 모아요. 중지하거나 연결이 끊겼다면 해당 탭의 [이어하기]로 마지막 완료 회차 다음부터 조회해요. 미완료 회차는 다시 조회해요.
- 옵션: 순위별 평균 입찰가(PC·모바일 1~5위, 기본 켬), 블로그 누적 발행량·포화 지수(검색 API 키가 있을 때, 기본 켬).
- 진행률이 단계별로 표시되고, 받은 결과부터 표가 바로 채워져요. [중지]하면 받은 데까지 남아요.
- 표는 정렬, 키워드 검색, 최소·최대 검색량, 경쟁 정도 필터를 지원하고, 필터한 그대로 엑셀·CSV로 받을 수 있어요(입찰가는 1~5위 전부 포함). 키워드를 누르면 상세 분석으로 넘어가요.
- 결과는 12시간 캐시를 써서 같은 키워드를 다시 조회하면 빨라요. 마지막 결과는 브라우저에 남아 다시 열어도 보여요.

## 설정 (오른쪽 위 [설정])

- **API 설정**: 네이버 API / AI 모델 키 입력 (예전 API 설정 창).
- **화면 · 커스텀**: 사이트 이름, 강조 색, 화면 배율, 표 간격, 숫자 표기, 시작 화면, 숨길 상단 버튼, 표 한 페이지 행 수, 설정 내보내기·불러오기(JSON).
- **규칙 · 알고리즘**: 각 기능의 계산 원리 설명과 바꿀 수 있는 기준.
  - 키워드 분석: 포화 지수 구간, 키워드 등급 기준, 이슈성 구간, 정보성/상업성 단어·가점·구간
  - AI 생성: AI 역할 문장, 생성 규칙, 띄어쓰기 없애기, 창의성(Gemini)
  - 조건 재검증: 판정 기준, 검색량 참고 여부, '일관' 횟수, '<10' 계산값, 새 탭 최소 검색량, 창의성(Gemini)
  - 중복 검사(AI 생성기·중복 검사 탭 공통): 무시할 기호, 대소문자, 어순, 1글자 차이·포함 최소 길이, 숫자 규칙, 의미 중복 후보 기준, 같은 말 사전
- 화면·규칙 설정은 data\settings.json에 저장돼요. 섹션마다 [기본값으로], 전체 초기화도 있어요.

## 대량 분석 > AI 조건 재검증

- 분석 결과가 있으면 결과 위에 'AI 조건 재검증' 칸이 생겨요. 주제·예시·요청 사항·최소 월간 검색량을 넣거나, [조건 가져오기]로 AI 키워드 생성기 탭의 조건을 그대로 가져올 수 있어요.
- 대상: 전체 / 지금 표에 보이는 키워드(필터 적용) / 체크한 키워드. 50개씩 묶어서 AI에 보내요.
- 판정 방식은 AI 생성기 재검증과 같아요(설정 > 규칙·알고리즘 > 조건 재검증). 최소 검색량 미만은 PC가 부적합 처리.
- 표에 'AI 판정' 열(일관 적합/엇갈림/부적합 + 판정 기록 점), 판정 필터, 체크박스, [부적합만 체크] → [체크한 키워드 삭제].
- 엑셀/CSV에 AI 판정, 적합/판정 횟수, 최근 판정 근거 열이 추가돼요.

## 대량 분석 > 내역 탭 · 재검증 AI 선택

- 왼쪽 사이드바에 분석 내역이 쌓여요. [분석 시작]을 누를 때마다 새 탭이 만들어지고, 결과가 있는 탭에서 다시 분석해도 이전 결과는 내역에 남아요 (재검증 조건은 이어받음).
- 탭 우클릭: 상단에 고정 / 이름 변경 / 삭제. 이름은 파일명이나 '첫 키워드 외 N개'로 자동으로 붙어요.
- 결과·판정 기록·재검증 조건은 data\bulk-history\ 폴더에 탭마다 파일로 저장돼요 (index.json = 목록). 예전 버전의 마지막 결과는 처음 열 때 내역으로 옮겨져요.
- AI 조건 재검증 칸에서 AI(Gemini/Claude/GPT)와 모델을 따로 고를 수 있어요. AI 키워드 생성기의 선택과는 별개로 기억하고, 전체 설정은 바꾸지 않아요. 키가 없는 AI는 '(키 없음)'으로 표시돼요. '모델 고정' 설정은 공통이에요.

## 결과 필터 (대량 분석 · 키워드 중복 검사 · AI 생성기 공통)

- 키워드 검색(여러 단어는 띄어쓰기, 모두 포함), 제외 단어, 숫자 범위(최소~최대, 그 값 포함). 쉼표(1,000)도 돼요.
- 대량 분석: 월간 검색량 + [상세 필터]에 PC·모바일 검색량, 월 클릭, 클릭률, 광고수, PC/MO 1·3위 입찰가, 블로그 누적, 포화 지수, 글자 수.
- 중복 검사: 글자 수 범위. 필터가 켜져 있으면 다운로드·복사도 필터에 맞는 키워드만. [남은 키워드 대량 분석 →]으로 검색량 조회까지 이어서.
- AI 생성기: 월간 검색량, PC, 모바일, 글자 수.
- 최소가 최대보다 크거나 숫자가 아니면 빨갛게 표시돼요. 값이 없는 키워드는 범위를 지정하면 빠져요.

## AI 생성기 자동 저장

- 새 탭은 주제가 없어도 예시·요청 사항 중 하나라도 적으면 기록에 올라가요.

## 판정 엇갈림 정리 (AI 생성기 · 대량 분석)

- 재검증이 끝났을 때 판정이 엇갈린 키워드가 있으면 창이 떠서 적합 / 부적합 / 보류를 물어봐요. [엇갈림 정리] 버튼이나 표의 '어느 쪽으로 할지 정하기'로도 열 수 있어요.
- AI가 댄 부적합 사유별로 묶어서 보여주고, 묶음 단위·전체 단위로 한 번에 고를 수 있어요.
- 고른 결과는 '적합 (직접)' / '부적합 (직접)'으로 확정되고 다음 재검증에서 빠져요 (체크한 키워드 대상이면 포함). 보류는 엇갈림 그대로.
- '내 결정을 AI에게 예시로 알려주기'(기본 켜짐): 다음 재검증 때 최근 결정 60개를 판정 기준 아래에 예시로 붙여 비슷한 키워드를 같은 기준으로 판정하게 해요.
- 표의 [직접 판정 취소]로 되돌릴 수 있고, [판정 기록 지우기]는 직접 판정도 함께 지워요.

## AI: Gemini API 키 + 로그인형 (Gemini · Claude · GPT)

- Claude·GPT API 키 연동은 삭제했어요 (요금 발생). 예전에 저장한 Claude·GPT 키는 서버를 켤 때 config.json에서 지워요.
- Gemini는 API 키 방식을 그대로 두었고, 로그인형 3가지를 추가했어요. 각 회사 공식 CLI를 이 PC에서 실행해 구독 계정으로 써요 (API 요금 없음, 구독 사용 한도 적용).

  - Claude (로그인): Claude Code (claude -p). Claude Pro·Max 등 구독.
  - GPT (ChatGPT 로그인): Codex CLI (codex exec). ChatGPT 계정.
- 설정 > API 설정 > AI 모델 > 로그인형 AI: [설치]만 누르면 자동으로 이어져요. 설치 창이 끝나면 확인 → 로그인이 안 돼 있으면 로그인 창을 열어줌 → 브라우저에서 로그인하고 창이 닫히면 자동 테스트. 그다음 [이 AI 쓰기].
- 모델 칸을 비워두면 각 CLI의 기본 모델. 실행 파일을 못 찾으면 '실행 파일 위치'에 직접 지정.
- 로그인형은 매번 프로그램을 띄워서 API보다 느리고(10~60초), 생각 과정 표시가 없어요. 빈 임시 폴더에서 실행하고 파일·명령 도구는 막아요. 환경 변수의 API 키는 넘기지 않아요 (항상 로그인 계정 사용).

8. [네이버 모양으로 보기], [목업] (광고 목업에 넣기), TXT · CSV · 엑셀

- **검사 규칙** 버튼: 사용자 주의어(처음엔 비어 있음), 최상급 검사 켜기/끄기와 단어 목록

## 파워링크 분석기 (왼쪽 메뉴)

파워링크 표를 머리글부터 엑셀에서 복사해 붙여넣으면, 다운로드의 첫 원본 탭에 기존 열·행·값을 그대로 두고 오른쪽에 키워드별 실측 순위·입찰가·예상 실적·분석 상태를 붙여요. 예를 들어 원본이 A~R열이면 S열부터 추가돼요. 복사한 표에서는 원본 통합문서의 서식과 수식 자체가 아니라 붙여넣은 셀 값을 보존해요.

열 순서는 바꿔도 돼요. 머리글을 포함하면 키워드와 실적 항목을 이름으로 찾고, 다운로드에서도 입력한 열 순서를 유지해요.

### 두 기간 실적 비교

1. 새 분석이나 같은 키워드 재분석에서 광고관리 키워드 실적 파일과 보고서 시작일·종료일을 넣어요. 기존 분석도 결과의 **실적 파일·기간 설정**에서 보완할 수 있어요. 이전 파일 없이 재분석하면 이전 기간 실적은 복사하지 않아요.
2. **두 기간 비교**에서 기준(이전)과 비교(이후) 분석을 골라요. 같은 광고 URL·계정·보고서 범위, 겹치지 않는 기간을 사용하세요. 실제 노출·클릭은 머리글(키워드 / 노출수 / 클릭수)이 있는 시트에서 읽어요. 중복 행, 한쪽 누락은 0으로 바꾸지 않아요. 기기나 광고그룹별로 같은 키워드가 반복되는 보고서는 먼저 키워드별로 합산한 단일 보고서를 넣으세요.
3. PC·모바일 순위는 분석 시점 검색의 스냅샷이며 기간 평균이 아니에요. 실제 노출·클릭은 기간 합계와 일평균으로 비교하고, 클릭 하락을 노출 변화·CTR 변화로 분해해 점검할 항목을 제시해요. AI나 외부 서비스로 실적 파일을 보내지 않아요.
4. 결과 엑셀에는 원본 목록과 모든 입력 시트의 셀 데이터가 포함돼요(수식은 저장된 계산값). 서식·수식·매크로까지 필요한 경우 결과 화면의 파일명 링크로 업로드 원본을 그대로 내려받으세요. 새 파일을 첨부해 저장하면 그 분석의 원본 세트를 교체해요. 파일당 12MB, 서버 요청 전체 25MB 제한이 있어요.

- 내 파워링크 URL(고유번호·추적값 없어도 됨)을 넣고, 네이버 광고관리 **키워드 다운로드 엑셀**을 그대로 넣으면 키워드·입찰가·상태를 읽어요('노출가능'만 체크).
- 키워드마다 로그아웃 상태 네이버 '광고 더보기'(PC 최대 25위 · 모바일 15위)를 여러 번(설정 ⑥, 기본 4회) 열어 평균 순위를 내요. AI는 쓰지 않아요.
- 캡처: 이 PC의 Edge(없으면 Chrome)를 화면 없이 띄워 통합검색 파워링크 영역을 찍고 내 광고에 빨간 테두리. 통합검색 밖이면 광고 더보기 화면.
- n위 입찰가 = 검색광고 API 순위별 평균 입찰가(최근 4주), n위 예상 = 그 입찰가의 예상 실적(월). 표 머리에서 n을 바꿀 수 있어요.
- **열 맞춤 설정**: 저장된 분석의 결과 표 위에서 버튼을 누르면 가운데 팝업이 열려요. 열을 체크하고, 끌거나 ↑↓로 순서를 바꾼 뒤 **저장**하세요. **취소**나 Esc로 닫으면 이전 설정을 유지해요. 키워드는 맨 왼쪽에 고정돼요. 실적 보고서를 연결한 분석에서는 보고서 머리글을 검색해 선택할 수 있어요. 보고서 원본 값은 기기 탭과 별개이며, 없는 값과 중복으로 확정할 수 없는 값은 0으로 표시하지 않아요. 설정은 같은 브라우저의 다음 분석에도 적용되고, 보고서에 없는 열은 다시 등장할 때까지 숨겨져요. 이 설정은 화면만 바꾸고 다운로드에는 영향을 주지 않아요.
- 엑셀 다운로드: PC·모바일 시트, 줄마다 내 광고 주변 캡처 그림. 원본 캡처는 `data\powerlink\<작업>\` 폴더.
- 네이버 검색 제한을 피하려고 검색 사이 1.2초(설정), 제한에 걸리면 1분부터 점점 길게 쉬었다 자동으로 이어가요. 중지 후 [이어서 하기] 가능.

### 순위 추적 (켜 두면 계속 확인)

입찰가를 바꾼 뒤 내 파워링크가 몇 위로 움직이는지 계속 확인해요. 왼쪽 메뉴 **분석 · 운영 › 순위 추적** → **+ 새 추적**. 추적 중이면 메뉴에 '추적 중 n'이 보여요.

1. 내 파워링크 URL과 키워드를 넣어요. **키워드 파일**(광고관리 키워드 다운로드 엑셀)을 넣거나 엑셀 표를 머리글부터 키워드 칸에 붙여넣으면 키워드와 **최초 입찰가**를 같이 읽어요('노출가능'만). 표에 '최초 입찰가' 열이 생기고, 입찰가 기록 옆에 최초 대비 증감이 보여요. **분석에서 가져오기**로 지난 분석의 URL·기기·키워드를 불러올 수 있어요. 목표 순위는 "키워드, 3"(PC·모바일 같게) 또는 "키워드, 3, 2"(PC, 모바일 · 없으면 -)로 같이 쓰거나 표에서 바로 바꿔요.
2. 확인 간격(기본 5분), 키워드 상한(기본 30개), 추적 시간을 골라요: **24시간 계속** / **매일 정한 시간에만** / **시작부터 30분·1시간 … 또는 직접 입력** 뒤 자동으로 멈춤.
3. **저장하고 시작**. 확인은 서버(start.bat 창)가 해서 브라우저 탭을 닫아도 계속돼요. PC를 끄거나 절전이면 멈추고, 서버를 다시 켜면 이어가요.
4. 네이버 광고관리에서 입찰가를 바꿨으면 그 줄의 **+ 기록**에 새 입찰가를 적어요. 그래프에 세로선이 생기고, 그 키워드만 **20분 동안 1분마다** 확인해요(집중 확인). 실제 입찰가는 바뀌지 않아요.
5. **알림**을 켜면 목표 순위에 닿거나 밀릴 때, 광고가 안 보일 때, 추적 시간이 끝났을 때 화면 알림과 윈도 알림이 나와요. 순위가 검색마다 조금씩 흔들려서 같은 상태가 2번 연속일 때만 알려요. 키워드 분석기 탭이 열려 있어야 알림이 떠요(어느 메뉴든 괜찮아요).

- 확인 방법은 분석기와 같아요: 로그아웃 상태 '광고 더보기' 화면을 1번 열어 순위만 읽어요. 클릭·캡처는 안 해요. `더보기 n위` = 통합검색 밖(PC 11위~, 모바일 6위~).
- 분석기와 검색 간격(설정 ⑥)을 함께 써서 둘이 동시에 돌아도 네이버 검색 총량은 늘지 않아요. 대신 분석이 조금 느려져요.
- 키워드가 많거나 간격이 짧으면 네이버 검색 제한에 걸릴 수 있어요. 걸리면 자동으로 쉬었다 이어가지만, 그동안 이 PC에서 네이버를 검색할 때 자동입력 방지 문자가 나올 수 있어요. 새 추적 창에서 한 바퀴 시간과 하루 검색 수를 미리 보여줘요.
- 기록은 `data/powerlink/track/`에 30일 보관하고 GitHub에는 올리지 않아요. **엑셀**은 그래프 아래에서 고른 기간의 확인 기록과 입찰가 기록이에요.

### 화면 연결과 상태 표시

기능과 기록은 왼쪽 메뉴에서 찾으세요. 상단에는 현재 화면 이름과 **초기화·테마 전환·설정** 버튼이 표시돼요. 다른 화면에서 대량 분석·AI 생성·파워링크 분석이 진행되거나 대량 분석을 이어할 수 있다면 **작업 N**을 눌러 돌아갈 수 있어요.

파워링크 비교에서 기준·비교를 선택한 채 자료와 기간을 수정할 수 있어요. 좁은 화면에서는 표 아래에 하락 진단을 보여줘요. 네이버 검색은 최신 요청만 반영하고 섹션 실패는 따로 재조회할 수 있어요. 대량 분석은 저장이 끝난 건수와 필터 파일 범위를 표시하고, 대량·AI 진행 중 다른 메뉴에서는 상단에 돌아가기 버튼이 나와요. 브라우저를 닫아도 작업이 계속된다는 뜻은 아니에요.

### 새 작업에 제목 붙이기

파워링크 분석기, 대량 분석, AI 키워드 생성기, AI 카피 생성기, 광고 목업에서 새 작업을 열면 화면 위에 **작업 제목**이 보여요. 제목을 입력하면 왼쪽 작업 목록에 그 이름으로 표시돼요. 비워 두면 기존 방식으로 자동 제목을 정해요. 광고 목업에서는 `+ 새 캠페인` → 제목 입력 → 캠페인 종류 선택 순서예요.

### 네이버 키워드 입찰가 조정

1. 왼쪽 **키워드 입찰가 조정**에서 데일리리포트와 네이버 키워드 파일을 넣어요. 파일을 못 열면 엑셀 표를 머리글과 함께 붙여넣으세요. 열 순서는 상관없어요. 데일리에 광고그룹 소계가 있으면 **광고그룹 이름**에 소계 행과 같은 이름을 입력하세요.
2. 광고그룹·기기·목표 CPA, 데일리 성과 기간, 네이버 조회 기간과 다운로드일을 입력해요. 네이버에서 **같은 기간**으로 조회한 파일을 사용하세요. 날짜 입력은 집계표를 잘라내지 않고, 파일의 조회 기준을 확인해요. 기간·목표 또는 성과 자료가 불충분하면 자동 추천을 보류해요. 광고그룹·기기가 확인되지 않거나 네이버 파일이 오래됐을 때는 수동 입력값도 CSV에 내보낼 수 없어요.
3. **신청하기**는 전환(대시 표기는 0, 빈칸은 미확인), **추정 실적 ÷ 비용**은 추정 ROAS로 읽어요. 비용·클릭·전환은 데일리만 사용해요. 하향은 30클릭 이상에서, 전환 0건이면 지출이 목표 CPA의 2배 이상, 전환이 있으면 3건 이상에 CPA가 목표보다 25% 이상 높을 때 최대 10% 조정해요. 이전 데일리(동일 범위·같은 길이·비중복 기간)로 순위 하락을 확인하고 CPA 여유가 있을 때만 최대 5% 상향을 검토해요. 순위와 ROAS 개선은 보장하지 않아요.
4. 생성기와 같은 입찰 검토 표에서 **현재가 / 자동 추천가 / 최종 입찰가 / 증감**을 키워드 옆에서 비교하세요. 열 제목으로 정렬하고, 보류 사유를 클릭해 해당 유형만 볼 수 있어요. **집중 피킹**은 현재 페이지에서 ↑↓ 이동, Space 체크/해제, Esc 종료를 지원해요. 머리글 체크는 현재 페이지, **필터 전체 변경 후보 선택**은 다른 페이지를 포함한 현재 필터의 변경 후보까지 선택해요. 자동 추천이 보류된 행도 안전하게 매칭됐으면 최종가를 직접 입력할 수 있어요(70~100,000원, 10원 단위). 행을 체크하고 **선택 적용 → 네이버 양식 CSV 다운로드**를 눌러요. 적용 뒤 가격을 다시 바꾸면 그 행을 재적용해야 해요. 중복 ID, 미매칭, 그룹 불일치, 노출 불가, 개별 입찰가가 아닌 행은 제외해요. 현재 필터의 적용분만 담고, **검토 TXT**는 현재 필터의 근거를 기록해요. 원본 CSV의 1~6행, CP949와 CRLF는 그대로 두고 7행부터 네이버용 값만 작성해요. 툴에서는 광고 계정에 업로드하지 않아요. 네이버 업로드 전에 최신 입찰가를 다시 확인하세요.

행의 **AI 진단**은 네이버 시장 지표와 성과 근거를 먼저 열어요. 연결된 모델을 고르고 **AI로 원인 해석**을 눌러야 AI가 실행돼요. AI는 근거와 확인할 항목을 설명할 뿐, 추천가·최종가·CSV를 바꾸지 않아요.

자료와 캠페인별 목표 CPA는 현재 브라우저에만 저장돼요. 왼쪽 내역에서 다시 열 수 있고, 승인했던 항목은 다시 검토하도록 초기화돼요.

#### 입찰가 트래킹

입찰 조정 결과에서 **트래킹에 저장**을 눌러 전체 키워드의 성과, 목표 CPA, 현재 입찰가·승인안·CSV에 담긴 값을 보관해요. CSV로 내보낸 값까지 남기려면 다운로드한 뒤 저장하세요. 저장한 기록은 변경되거나 덮어쓰지 않아요. 다음 달에도 새 결과를 저장한 뒤 **입찰가 트래킹**에서 기준·비교 기록을 선택하세요. 같은 광고그룹과 기기만 비교하고, 다음 달 같은 날짜 범위가 있으면 우선 제안해요. 일수가 다르거나 기간이 겹치면 성과 등락으로 판정하지 않아요. CSV 일치 여부는 새 파일에서 관측한 값과 비교한 결과이며 업로드나 실제 반영 시각을 뜻하지 않아요.

트래킹 기록은 이 PC의 프로젝트 `data/bid-tracking/`에 저장돼요. 브라우저 검토 내역과 별개이며 GitHub에는 올라가지 않아요. PC를 옮길 때 이 폴더를 별도로 복사하세요.

#### 시장·성과 진단 (선택)
