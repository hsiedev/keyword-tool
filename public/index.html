① 네이버 검색광고 API (검색량, 연관 키워드, 입찰가)
  1. searchad.naver.com 가입 및 로그인 (광고비 충전 필요 없음)
  2. 광고시스템 > 도구 > API 사용 관리 > 네이버 검색광고 API 서비스 신청
  3. 액세스 라이선스, 비밀키, CUSTOMER_ID를 아래에 붙여넣기
② 네이버 검색 · 검색어 트렌드 API (트렌드, 발행량, 성인 여부)
  1. 네이버 클라우드 콘솔 로그인 (네이버 아이디로 가입 가능, 결제수단 등록이 필요할 수 있음)
  2. Menu > All Services > Application Services > NAVER API HUB > Application > [Application 등록]
  3. API에서 검색(Search), 검색어 트렌드(Search Trend) 선택 후 완료
  4. Application 선택 > API 관리 > [인증 정보]에서 Client ID, Client Secret 복사
사용할 AI (AI 키워드 생성기 · 재검증 · 의미 중복 검사)
끄면(기본) 모델이 바쁜 동안 같은 AI의 다른 모델로 자동 전환해요. 켜면 같은 모델로 약 70초 동안 5번 재시도하고, 그래도 안 되면 멈추고 알려줘요.
Gemini API 키 · 키로 쓰는 방식 (무료 등급 있음)
  1. Google AI Studio API 키 페이지에서 개인 구글 계정으로 [API 키 만들기]
  2. 무료 등급이 있지만, 무료로 쓰면 보낸 내용이 구글 모델 개선에 쓰여요.
로그인형 AI (API 요금 없음 · 구독 계정으로 로그인)
각 회사의 공식 프로그램(CLI)을 이 PC에 설치하고 한 번 로그인해 두면, 분석기가 그 계정으로 AI를 써요. API 키·충전이 필요 없고, 대신 각 구독의 사용 한도가 적용돼요. 실행할 때마다 프로그램을 띄우느라 API보다 느려요(한 번에 10~60초).
[설치]만 누르면 나머지는 자동이에요: 설치가 끝나면 확인 → 로그인이 안 돼 있으면 로그인 창 → 창이 닫히면 테스트. 브라우저에서 로그인만 해주세요.
